# 资料契约

下列记录为确定性生成的本地合成资料，不含真实主体信息。不同文件通过标识字段关联，版本、生效时间、缺失状态和回执字段保留原始业务含义。

| 文件 | 字段 | 记录数 |
| --- | --- | ---: |
| `orders.csv` | `order_id`, `sku`, `lot_id`, `channel`, `sold_at`, `units`, `policy_version` | 120 |
| `returns.csv` | `return_id`, `order_id`, `returned_units`, `reason_code`, `received_at`, `refund_state`, `review_state` | 65 |
| `reason_map.csv` | `reason_code`, `category`, `valid_from`, `valid_to`, `mapping_version` | 16 |
| `inspections.csv` | `inspection_id`, `lot_id`, `sample_size`, `finding_code`, `severity`, `review_state`, `inspected_at` | 45 |
| `actions.csv` | `action_id`, `lot_id`, `owner_role`, `action_type`, `decision_state`, `effective_at`, `receipt_ref` | 39 |

数据缺失、待审、争议和未回执均表示状态未知或处理中，不能解释成零值或成功。记录中的模拟日期用于复现跨期关系，不表示真实业务发生。
